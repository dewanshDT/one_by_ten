# One by Ten

**Design. Develop. Grow.**

A modern "Coming Soon" landing page for a design, development, and marketing agency that helps startups transform bold ideas into beautiful products.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the landing page.

## ✨ Features

- 🎨 **Minimalist design** inspired by The Browser Company
- 🎞️ **Film grain texture** for sophisticated aesthetic
- ✍️ **Bentham font** - Elegant serif Google Font for headlines
- 🧘 **Clean, static background** - No cursor tracking or distracting animations
- ⚡ Subtle fade-in animations with Framer Motion
- 📱 Fully responsive design
- 📧 Simple email capture form (ready for API integration)
- 🎯 SEO optimized with meta tags
- 🎭 Beautiful UI with TailwindCSS v4
- ⚙️ TypeScript for type safety
- 💎 Timeless, memorable design aesthetic

## 🔧 Tech Stack

- **Next.js 16** - React framework
- **TypeScript** - Type-safe code
- **TailwindCSS v4** - Styling
- **Framer Motion** - Animations
- **Bentham** - Elegant serif Google Font for headlines
- **Geist Font** - Clean body typography
